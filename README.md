# 📬 MailMate

MailMate is a Java desktop application designed to intelligently organize, analyze, and manage Gmail emails. Instead of acting as another email client, MailMate serves as a personal email assistant that helps users identify important emails, summarize long messages, detect spam, verify internship opportunities, and generate daily inbox summaries.

---

## 🚀 Project Vision

Students and professionals often receive hundreds of emails every week. Many of these emails contain internship offers, college announcements, promotional content, newsletters, and important documents.

MailMate aims to reduce information overload by helping users quickly understand which emails require their attention.
